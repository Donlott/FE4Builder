# FE4 Nightmare modules

Downloaded on 2026-10-11.

- `FE4 Nightmare modules/`: base FE4 collection from https://github.com/laqieer/Fire-Emblem-Nightmare-Modules (main branch).
- `DefaultFormat additions/defaultformatnightmare/FE4 Nightmare modules/`: additional and modified modules by DefaultFormat, from https://feuniverse.us/t/fe4-various-new-nightmare-modules/22481 . Original download: https://drive.google.com/file/d/1KAnJRoVuONkeU2DBKj6NHqkiGBIV7ngE/view . Consult the included author's readme for module-specific instructions.

The packages remain separate so overlapping module and reference files are preserved. All companion files retain their original relative paths.

`upstream-modules.zip` is the original repository archive (also contains other games); only its FE4 folder was extracted. `defaultformatnightmare.zip` is the original additional-module archive.

These are upstream downloads, not yet validated against the project's translated ROM. Before implementing ROM writes, verify module offsets and copier-header assumptions against that ROM.
